# Google Apps Script per al formulari

1. Obre https://script.google.com
2. Crea un nou projecte
3. Copia el contingut de Code.gs i appsscript.json
4. Desa el projecte
5. Publica > Deploy > New deployment
6. Tria Web app
7. Executa com: Me
8. Accés: Cualquier persona
9. Desplega i copia la URL del web app
10. Canvia la constant GOOGLE_SCRIPT_URL al fitxer src/App.tsx amb aquesta URL
